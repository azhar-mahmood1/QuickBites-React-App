 QuickBites

QuickBites is a full-featured food restaurant delivery application built using the **MERN** stack (MongoDB, Express.js, React.js, Node.js).
 It provides users with a seamless experience to browse menus, place orders, and get delicious meals delivered right to their doorstep.

## Features

* Browse a wide variety of restaurants and food items
* User authentication and profile management
* Add items to cart and place orders easily
* Real-time order tracking
* Admin panel for managing restaurants, menus, and orders
* Responsive and intuitive user interface

## Technologies Used

* MongoDB for database management
* Express.js as the backend framework
* React.js for building the frontend UI
* Node.js for server-side runtime environment
